Turning the cloud back on

If you pause the five schedules and run locally, everything above stays in place and an idle setup costs a few dollars a month for secrets and image storage. To resume:

  1. Rebuild the image from main with the cti-pipeline-build CodeBuild project.
  2. Confirm the task definitions use MODEL_BACKEND=bedrock, Sonnet for the scan and Haiku for BUILD_MODEL.
  3. Enable the five schedules in the cti-pipeline group.
  4. Run one bulletin scan by hand and read its [cost] line in CloudWatch before trusting the cron.

Every step explained: docs/aws-setup-guide.md. Running locally: docs/local-setup.md.
